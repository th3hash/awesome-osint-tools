# Contributing to Awesome OSINT Tools

Thanks for taking the time to improve this collection!

## Types of contributions

- Add a new OSINT tool or service
- Improve descriptions or categories
- Fix broken links
- Add usage notes or legal/ethical caveats

## Before you start

- Make sure the tool is **legitimate**, **OSINT-focused**, and has a **clear use case**.
- Prefer open-source tools or well-established services.

## How to add a tool

1. Open an issue using the **OSINT tool request** template, or
2. Fork the repo and create a pull request:
   - Add the tool under the correct section in `README.md`
   - Keep the format consistent:
     - Name – one-line description.
     - Repo or website link.
     - Optional: extra note if it is paid/limited/free.

## Style guidelines

- Keep descriptions short and clear.
- Do not include proof-of-concept malware, botnets, or tools intended primarily for abuse.
- Focus on investigative, monitoring, and defensive use cases.

## Code of Conduct

By contributing, you agree to act respectfully and avoid promoting:

- Illegal activity
- Harassment or targeting of individuals
- Any form of discrimination

If you are unsure whether a tool fits, open an issue and we can discuss it.
