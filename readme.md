## What is OSINT?

Open Source Intelligence (OSINT) is the practice of collecting and analyzing information from publicly available sources like websites, social media, domain records, and leaked databases to generate actionable intelligence for security, investigations, journalism, and more. [web:4][web:15]

## Automation & Recon Frameworks

Frameworks that automate data gathering from multiple sources.

- **SpiderFoot** – OSINT automation platform with 200+ modules and web UI.  
  - Repo: https://github.com/smicallef/spiderfoot [web:5][web:8]

- **Recon-ng** – Metasploit-style web recon framework with modules, workspace, and API integrations.  
  - Repo: https://github.com/lanmaster53/recon-ng [web:6][web:12]

- **theHarvester** – Gathers emails, subdomains, IPs and more from public sources.  
  - Repo: https://github.com/laramies/theHarvester [web:9][web:12]

- **FinalRecon** – Lightweight web reconnaissance tool for gathering HTTP and website info.  
  - Repo: https://github.com/thewhiteh4t/FinalRecon [web:9]

## People, Email & Username OSINT

Tools for investigating identities, emails, and online aliases.

- **Have I Been Pwned** – Check if an email appears in known data breaches.  
  - Website: https://haveibeenpwned.com [web:12]

- **BeenVerified** – People search and background info (paid, but heavily used in OSINT workflows).  
  - Website: https://www.beenverified.com [web:12]

- **CheckUserNames / KnowEm** – Check username availability/existence across many platforms.  
  - Website: https://knowem.com [web:12]

- **GHunt** – Investigate Google accounts (Gmail, Photos, Maps, etc.) using public information.  
  - Repo: https://github.com/mxrch/ghunt [web:8]

## Metadata & File Analysis

Extracting metadata from documents and images to reveal hidden info.

- **ExifTool** – Read, write, and edit metadata in a wide range of file types.  
  - Website: https://exiftool.org [web:12]

- **Metagoofil / metagoofil** – Extract metadata from public documents (PDF, DOC, etc.).  
  - Repo: https://github.com/laramies/metagoofil [web:8][web:12]

- **FOCA** – Fingerprinting Organizations with Collected Archives, for document metadata analysis.  
  - Repo: https://github.com/ElevenPaths/FOCA [web:12]

## How to Contribute

Contributions are welcome! If you know a solid OSINT tool that should be listed here:

1. Check if it is already included.
2. Open an issue using the **“OSINT tool request”** template.
3. Include:
   - Name of the tool
   - Link (GitHub repo or official website)
   - Short description (what it does and primary use case)
   - Category suggestion

You can also submit a pull request that adds the tool directly to the relevant section.
